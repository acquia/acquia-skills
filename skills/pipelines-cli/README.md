# pipelines-cli Skills

Command-line skills for [Acquia Pipelines CLI](https://docs.acquia.com/acquia-cloud-platform/using-cloud-platform-pipelines-client).

## Skills

| Skill | Description |
|-------|-------------|
| [getting-started](getting-started/SKILL.md) | Install, configure credentials, verify connection, and update the CLI |
| [application-management](application-management/SKILL.md) | List applications and codebases, link/unlink repos to application IDs |
| [pipeline-operations](pipeline-operations/SKILL.md) | Trigger pipelines, check status, view logs, and terminate jobs |
