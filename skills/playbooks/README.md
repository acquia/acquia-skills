# Workflow Skills

Cross-product skills that chain multiple tools into end-to-end workflows.

## Skills

| Skill | Description |
|-------|-------------|
| [drupal-update-deploy](drupal-update-deploy/SKILL.md) | Update Drupal dependencies, push code, deploy to environment, and optionally trigger a pipeline |
| [canvas-headless-onboarding](canvas-headless-onboarding/SKILL.md) | Configure Drupal Canvas headless end to end: enable `canvas_headless`, scaffold or wire a decoupled frontend, split the frontend URL per Cloud environment, and deploy to Front End Hosting |
